# 桌面智能体文本模型

造物桌面端的文本地址、密钥和协议继续在「设置 → 个人渠道」编辑。画布智能体、智能创作的文本规划及记忆压缩在首次使用个人模型时，通过桌面主进程同步对应渠道和模型到本机后端，随后只提交后端渠道 ID 与模型标识。

普通网页端继续要求后端受管模型。智能体准入接口不接收浏览器提交的上游地址和密钥。桌面桥接只接受本机主窗口和主 frame，使用固定的本机后端地址、当前本地管理员的登录 Cookie；一次同步过程中账号切换不会改变写入身份。

## 同步规则

- 后端复用管理渠道的地址校验、权限校验、协议校验与加密存储；密钥保存在本机后端的数据目录，以设置密钥加密。
- 渠道映射由当前用户 ID 与个人渠道 ID 决定。并发操作、失败重试和重启复用相同映射；每次新提交刷新选中模型的地址、密钥、协议及能力配置。
- 内部渠道使用 `造物桌面智能体/` 加摘要命名，桌面模型目录隐藏这些同步副本。个人渠道和模型选择保持原值，不在设置中出现重复模型。
- 仅同步选中的文本模型。未填密钥、停用渠道、选中模型已移除或同步失败时，停止新请求，不建立智能体运行。已提交的请求继续使用原幂等身份。
- 本机同步模型的应用内价格为零。模型供应商仍按实际调用收费；此配置不改变供应商价格。
- 已创建的智能体任务及已保存的定时记忆压缩引用后端配置。个人渠道的修改在下一次使用该模型时同步；删除个人渠道不会删除已有任务使用的后端记录。

图片和视频的普通本地生成入口保持现有服务连接。智能体的媒体工具仍要求后端受管媒体协议；文本桥接不表示本地图片视频协议已接入智能体工具。
