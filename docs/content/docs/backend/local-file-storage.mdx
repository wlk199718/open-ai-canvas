# 桌面端文件存储

造物桌面端在「设置 → 文件存储」提供唯一的保存位置设置。默认使用系统文档目录内的「造物文件」，内部按用途分为：

- `生成结果`：中间服务下载的图片与视频。
- `项目素材`：造物持久化的素材原件、上传文件和播放副本，继续按用户、类型与日期分类。

生成服务的「服务设置 → 通用 → 文件存储」显示统一位置、当前结果位置和同步状态，并提供打开结果目录按钮。它读取同一设置，不另设独立选择入口。

## 配置与生效

两个客户端通过 `%LOCALAPPDATA%\Zaowu\storage.json` 共享配置。选择文件夹时检查绝对路径、目录类型和写入权限；配置原子写入。路径包含目录链接、磁盘根或与当前素材目录相互包含时拒绝更换。

更换后显示待应用状态。点击「重启并应用」检查造物的活动任务和中间服务的活动任务，存在任务时拒绝重启。空闲时退出生成服务、重启造物，由造物重新启动生成服务；两端分别在启动阶段迁移自己管理的文件。

迁移复制原有文件并校验 SHA-256。相同内容可续接已经完成的复制，内容不同的同名文件不会覆盖。迁移失败会阻止对应服务启动，不以空目录继续工作；原文件仍保留。成功后更新素材根目录或中间服务任务的 `result_path`。后续启动只使用活动目录，不从旧备份补回已经删除的文件。

造物的资源 ID、对象 key、权限和文件 API 不变化；数据库继续位于原应用数据目录。中间服务的账号、卡密、任务数据库及参考图继续位于原服务数据目录。统一位置不代表文件去重：生成结果与造物项目素材仍分别持有副本，两个系统的删除和引用检查继续各自执行。

## 源码运行

- `CANVAS_RESOURCE_DIR`：造物后端的本地素材目录，必须是绝对路径。留空使用 `CANVAS_BACKEND_DATA_DIR/resources`。
- `ZAOWU_PROVIDER_RESULT_DIR`：中间服务的独立结果目录，必须是绝对路径。留空继续使用已生效的结果位置，首次使用服务数据目录下的 `results`。
- `ZAOWU_PROVIDER_DATA_DIR`：账号、授权和任务数据库的数据根，与结果目录设置独立。

两个桌面客户端分别注入前两项环境变量。网页端不提供任意服务器目录修改入口；桌面选择和打开目录通过校验主窗口来源的 Electron IPC 执行。

## 生成结果文件操作

桌面画布、批次图片、素材库和项目产物在操作入口检查原件是否确实保存在本机。文件存在时显示「打开所在文件夹」，通过系统文件管理器选中原件；「另存为」使用系统保存对话框直接复制原件。媒体预览保持原有行为，打开所在文件夹不生成第二份下载。

尚未落地的远程结果仍显示「下载」。本地文件已经移动、删除或目录不可访问时明确提示错误，不自动改成下载，以免重复保存或掩盖存储问题。生成服务桌面客户端的已完成任务也提供文件夹定位和另存为，浏览器管理页保留下载。

渲染进程只传资源 ID 或任务 ID。造物主进程通过登录态资源接口检查归属、状态及对象 key，生成服务通过管理会话的结果接口验证任务；随后限定到当前活动素材/结果目录，校验真实路径和文件存在，拒绝链接逃逸。不公开任意磁盘路径读写接口。

## Windows 覆盖安装

安装器先按当前和原安装目录请求旧客户端正常退出，等待后端释放文件；超时仅处理本产品可执行文件和子进程。无法关闭时停止覆盖，数据目录和生成文件不会被卸载清理。

升级临时目录设在原安装目录的同一磁盘，并使用短目录名，避免旧 NSIS 卸载器跨盘移动失败，或为 Agent 深层依赖增加过长路径。提权后的安装入口同样执行进程关闭和临时目录检查。安装器仍按原流程更新程序文件、快捷方式和卸载信息。
