# 造物 Windows 桌面包检查记录

检查日期：2026-10-11。检查对象：0.1.0 的 `release/win-unpacked/造物.exe` 及其内置 Go 后端、前端、Agent 运行时和 ffmpeg。

本次通过 Playwright Electron 驱动运行真实打包程序，使用独立测试数据目录。没有修改产品代码、原有用户数据库或已生成安装包。安装器的安装、升级、卸载流程不属于本次运行验证。

## 已复现的问题

### 1. P1：重启后个人模型渠道配置无法读取

位置：`src/backend.js:41`；`../web/src/stores/use-config-store.ts:375`；`../web/src/lib/user-scope.ts:35`。

每次启动随机选择后端端口；Electron 页面直接加载这个地址。个人模型渠道使用浏览器 localStorage 保存，其隔离范围包含端口。

在真实设置页新增测试渠道、填写测试 Base URL 和假 API Key，点击“完成”，同一次运行刷新页面，配置正常保留。关闭并重启相同测试数据目录后，地址从 `http://127.0.0.1:9768` 变成 `http://127.0.0.1:9849`，测试渠道不再出现在新地址的存储中，测试 localStorage 标记也读不到。

影响：渠道、密钥、模型选择及其他使用浏览器 origin 存储的配置会表现为重启后丢失。旧端口下的存储并非已经被删除，不能直接以此判断数据物理丢失。IndexedDB 同样按 origin 隔离，但本次没有单独验证未同步草稿。

作为对照，测试画布通过业务 API 成功保存，重启后仍返回 HTTP 200 和原画布标题；没有复现数据库画布丢失。

修复方向：为桌面页面提供稳定的 origin，并考虑已有端口下配置的迁移。不能在固定端口被占用时静默切换 origin，否则同一问题仍会出现。

### 2. P1：默认桌面包无法连接本地模型 API 服务

位置：`src/backend.js:47`；`../backend/internal/outbound/outbound.go:83`。

桌面包沿用服务器版本的出站访问策略，未提供本地模型服务的可信主机配置。

测试使用独立的 loopback HTTP 模型目录服务，通过真实登录会话请求 `/api/ai/custom`。返回 HTTP 400，原因是“自定义渠道 HTTP 仅允许访问已配置的可信上游主机”；测试服务收到的请求数为 0。

影响：按默认启动环境配置 `http://127.0.0.1:8787` 等本机供应商地址，不能直接拉取模型或调用生成。这是当前桌面配置与本机供应商接入需求之间的缺口，出站安全策略本身不是错误。

修复方向：桌面端提供明确的可信本地服务设置，精确放行必要主机并保留其他出站校验。已有环境配置 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 时，结果可能不同；本次验证的是未配置该值的默认安装包行为。

### 3. P1：视频合成文件校验允许读取上传工作区之外的文件

位置：`../backend/cmd/server/desktop_ffmpeg.go:45`、`:211`、`:225`。

concat 列表校验只处理形如 `file '名称'` 的行，对其他 FFmpeg 能识别的文件行没有拒绝。调用参数允许 `-safe 0`。

测试仅上传 concat 列表，引用测试程序预先生成、但没有上传的本机合成视频。真实接口返回 HTTP 200、`X-Ffmpeg-Exit-Code: 0` 和有效 MP4，证明 FFmpeg 读取到了上传工作区之外的文件。

影响：该接口声明的文件隔离边界不成立。接口仍要求登录和同源请求，本次未证明外部网站可以无会话调用，也未读取任何真实用户文件。

修复方向：严格限定支持的 concat 语法，拒绝未识别的指令，对所有文件引用验证其属于已上传文件，并限制可用协议与其他文件读取入口。

### 4. P2：数据库恢复后缺少本地凭据，会静默进入游客模式

位置：`src/local-account.js:9`、`:43`；`src/main.js:57`。

将测试数据库复制到独立新目录，不复制 `local-account.bin` 或浏览器 Cookie，模拟仅恢复数据库的情况。

启动后自动创建新的随机凭据，但已有 local 账号使用原密码，无法自动登录。窗口仍打开首页，显示“游客模式”，没有有效登录 Cookie，也没有明确的凭据恢复提示。

影响：数据库仍在，但用户无法通过自动登录访问原账号的数据；随机密码并非用户自行设置，缺少恢复路径。

修复方向：区分首次创建账号与已有数据库凭据缺失，显示明确错误并提供受本机权限约束的恢复流程。不要以游客首页掩盖初始化失败。

## 源码发现，尚未单独运行复现

- `src/backend.js` 继承全部父进程环境变量。虽然固定了 SQLite driver，但没有清除 `DATABASE_URL`；`../backend/cmd/server/main.go:58` 仍读取它作为 DSN，可能覆盖桌面默认数据库位置。`YINGCE_AGENT_URL` 和 `CANVAS_FFMPEG_PATH` 也可能改变随包运行时的行为。应明确桌面允许继承哪些部署配置。
- 自动登录失败与旧目录迁移失败都缺少面向用户的恢复提示。

## 已通过的验证

- 真实打包程序启动、首次自动创建账号、正常重启自动登录；主页面无白屏，监听期间没有页面脚本异常。
- 实际窗口设置：sandbox 开启、contextIsolation 开启、nodeIntegration 关闭。
- 测试画布保存并在重启后成功读取。
- 随包 ffmpeg 对合成视频成功转码，前端 `libx264` 参数经后端替换后产出有效 MP4。
- 随包 Electron Node 和随包 Agent 依赖，通过本机模拟模型桥接完成消息与会话事件流程；未调用真实模型。
- SQLite DSN、连接 pragma、桌面 ffmpeg 参数校验及 H.264 参数替换的专项测试通过；Agent runtime 包测试通过。这些测试通过不抵消上述真实运行发现。
- 测试关闭后，后端日志记录正常退出；最终进程检查没有遗留造物或 sidecar。
